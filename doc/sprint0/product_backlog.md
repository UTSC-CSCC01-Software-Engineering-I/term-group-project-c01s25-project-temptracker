**Product Backlog \- User Stories**

1. As a user, I want to upload water temperature data from my phone, so that I can easily contribute data while on site  
2. As a user, I want to be able to get contribution points, so that I can be rewarded for entering data  
3. As a user, I want to be able to reset my password, so that I can access my account even if I have forgotten the password  
4. As a user, I want to be able to login, so that I can access the temperature data that I have input  
5. As a user, I want to see temperature trends for a specific beach or area, so I can understand changes over time.  
6. As a user, I want to compare today’s water temperature to historical averages, so I can tell if it’s warmer or colder than usual.  
7. As a user, I want to filter temperature data on the map by time range (e.g., last week, month), so I can focus on recent or long-term data.  
8. As a user, I want to toggle between Celsius and Fahrenheit when viewing temperature data, so I can use the units I prefer.  
9. As a user, I want to download my uploaded temperature data as a CSV file, so I can keep a personal record or analyze it offline.  
10. As a user/admin, I want to be able to navigate between the different pages of the app (map, upload, settings) from a bottom navigation bar, so that I can easily access all the features of the app  
11. As a user, I want to be greeted with the website's name and logo in a top-down format, so I can easily identify the brand and the use case  
12. As a user, I want to create an account, so that I can keep track of the temperature data I’ve uploaded  
13. As a user, I want to upload water temperature data from my phone, so that I can easily contribute data while on site  
14. As a user, I want to see water temperatures visualized on a map with colour coded icons, so that I can quickly assess temperature conditions at different locations  
15. As a user, I want to create an account, so that I can keep track of the temperature data I’ve uploaded.  
16. As an admin, I want to be able to verify data submitted by users so that I can ensure its accuracy  
17. As a user, I want to be able to use the web application on my phone, so that i can fully use the website  
18. As a user, I want to earn badges by inputting data, so that I can be rewarded for my contributions  
19. As a user, I want to sort locations by temperature, so I can easily determine the range of temperatures  
20. As a user, I want larger buttons optimized for mobile, so that I can easily navigate the application
